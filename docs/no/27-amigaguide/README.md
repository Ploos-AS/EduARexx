# 27 – Bonus: ARexx og AmigaGuide

EduARexx publiseres selv som AmigaGuide. Det gir oss også en naturlig avansert lab: studenten kan undersøke hvordan dokumentasjon og automatisering kan møtes på Amiga.

## Sikkerhetsregel

Dokumentasjon skal aldri skjule en destruktiv handling bak en praktisk knapp. Interaktivitet skal være forståelig, dokumentert og i utgangspunktet ikke-destruktiv.

## Oppgave

Åpne `EduARexx.guide` på Amiga og naviger mellom M1–M5. Sammenlign den native opplevelsen med HTML/PDF-utgaven.

I en senere milepæl bygger vi generatoren som lager denne filen automatisk fra kurskilden.

# 06 – M1-prosjekt: PowerTool

Nå kombinerer vi fundamentene i ett program.

## Oppdrag

Lag `powertool.rexx` med følgende grensesnitt:

```text
rx powertool.rexx INFO
rx powertool.rexx COUNT 5
rx powertool.rexx GREET Per
rx powertool.rexx HELP
```

Programmet skal bruke:

- `PARSE ARG`
- `IF` eller `SELECT`
- minst én løkke
- minst én egen funksjon/prosedyre
- tydelig hjelp ved ugyldig input
- eksplisitt `EXIT`

## Bestått M1

Du skal kunne lese scriptet og forklare kontrollflyten uten å gjette. Du skal også kunne endre en kommando eller legge til en ny uten å skrive om hele programmet.

Neste milepæl er **M2 – Amiga Power User**, hvor ARexx begynner å styre AmigaDOS og det virkelige systemmiljøet.

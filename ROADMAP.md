# EduARexx Roadmap

## M0 — Foundation

- establish course architecture
- define beginner-to-expert progression
- Norwegian-first documentation structure
- create first introductory lessons and labs
- document licensing split between course material and code
- define emulator/runtime qualification strategy

## M1 — ARexx Fundamentals

- RexxMast and execution model
- first scripts
- variables and expressions
- strings
- conditions and loops
- procedures and functions
- `PARSE`
- basic error handling
- exercises and milestone project

## M2 — Amiga Power User

- AmigaDOS automation
- filesystem workflows
- Workbench-oriented workflows
- command environments
- reusable utilities
- startup and maintenance scripts
- backup and batch operations

## M3 — ARexx Ports

- port discovery
- `ADDRESS`
- sending commands to applications
- return values and result handling
- coordinating multiple applications
- application-specific command interfaces
- real-world automation labs

## M4 — Robust Automation

- tracing and debugging
- error and signal handling
- defensive scripting
- state management
- logging
- reusable libraries and conventions
- larger multi-file projects

## M5 — BBS and Networking

- terminal automation
- BBS workflows
- ABBS examples and ARexx doors
- networking workflows
- integration examples with Ploos-AS Amiga software where suitable

## M6 — Expert / Internals

- RexxMast architecture
- Exec message ports
- `RexxMsg`
- host environments
- result and argument internals
- implementing an ARexx host/port in C
- designing applications for automation

## M7 — Capstone

Build an **Amiga Automation Suite** that combines:

- command-line automation
- file operations
- multiple ARexx ports
- application orchestration
- logging
- configuration
- error handling
- reusable procedures

The target outcome is an Amiga power user who can both automate existing applications and design new software that participates cleanly in the ARexx ecosystem.
